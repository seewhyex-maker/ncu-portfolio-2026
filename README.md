## 项目简介

本仓库用于记录本学期的学习过程、实验任务、作业成果以及个人成长轨迹。内容包括但不限于：

- 每周学习记录
- 实验报告与总结
- 课程资料与参考内容
- 学习反思与提升计划
- 期末成果展示

通过持续维护本仓库，能够形成一个清晰、有序、便于展示的个人作品集。

## 使用说明

1. 每周都到对应的 `WeekXX/` 目录中更新：
   - `README.md` —— 本周学习内容与反思总结
   - `report.md` —— 本周正式实验报告
   - `code/` —— 本周实验源代码
2. 如需统一书写格式，可参考 `templates/` 中的模板文件。
3. 重要资料建议放入 `其他资料/` 或 `课程成果/`。
4. 每次完成新的内容后，应及时更新本 README 的目录结构与进度总览。

## 常用 Git 命令（初学者速查）

```bash
git status                 # 查看当前有哪些改动
git add .                  # 把改动暂存（准备提交）
git commit -m "说明文字"    # 提交一次快照
git push                   # 推送到 GitHub 远程仓库
```

提交信息建议写成「类型(位置): 说明」的形式，例如：

```text
feat(Week03): 完成实验任务一
fix(Week04): 修正实验数据记录错误
docs(Week05): 补充实验报告中的分析部分
```
