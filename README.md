## 使用说明
1. 每周都在对应的 WeekXX 目录中更新学习记录与实验总结。
2. 如需统一书写格式，可参考 `templates/` 中的模板文件。
3. 重要资料建议放入 `其他资料/` 或 `课程成果/`。
4. 每次完成新的内容后，应及时更新 README 目录说明，确保仓库信息完整。
