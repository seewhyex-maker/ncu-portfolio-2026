# 学习计划

## 个人目标
- 完成本学期课程学习计划
- 规范保存学习记录与实验成果
- 保持作品集持续更新
- 总结个人成长与收获

## 学习安排
### 第1-4周
- 熟悉课程要求
- 完成基础学习任务
- 建立个人作品集框架
- 完成前期实验记录

### 第5-8周
- 继续学习并应用相关知识
- 完成中期实验任务
- 整理中期学习成果

### 第9-12周
- 提升实践能力
- 完成项目类任务
- 记录问题与改进方向

### 第13-16周
- 完成收尾工作
- 制作期末总结
- 归档最终成果

## 自我检查
- 资料是否完整？
- 是否按周更新？
- 任务是否有总结？
- 作品集是否易于查看？

## 反思建议
每周写一段简短总结，记录：
- 本周学到了什么
- 哪些内容还不熟悉
- 下一步如何提升
